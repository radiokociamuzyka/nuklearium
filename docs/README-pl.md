# projekt Nuklearium 
projekt Nuklearium to próba opracowania zestawu oprogramowania wsparcia dla branży energetyki atomowej w Polsce z wykorzystaniem nowoczesnych technologii. Zestaw interdyscyplinarnych narzędzi i pakietów wiedzy z dziedzin powiązanych mogących mieć wpływ na postęp projektów: historii, fizyki, prawa, budownictwa, logistyki, ekonomii i sociologii.
